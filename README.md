# Arihant Provision Stores

Arihant Provision Stores is a modern web-based ordering platform for a local grocery shop. It allows customers to browse products, add items to a cart, choose delivery or pickup, and place orders online, while giving the store owner a simple admin dashboard to manage products and orders.

## About the Website

This project is designed to make the store more accessible by replacing phone-only ordering with a lightweight online experience. Customers can:

- browse the product catalog
- view discounts and item variants
- add items to a cart
- choose delivery or pickup
- place an order and receive confirmation

Admins can manage shop availability, orders, and inventory from a single dashboard.

## Current Tech Stack

- React 18 for the user interface
- Vite for fast development and builds
- Tailwind CSS for styling
- Supabase for authentication, database access, and real-time updates
- Lucide React for icons
- Vercel deployment support

## Project Structure

The app is organized around a simple single-page experience with:

- public-facing pages for browsing and ordering
- an authentication flow for customers and admins
- a cart and checkout experience
- an admin dashboard for store operations

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
